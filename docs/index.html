Features

비즈니스 가치를 배가시키는 핵심 기능

단순한 브라우저 모음을 넘어, 자동화와 보안 관점의 최고 스펙을 갖추었습니다.

100% 격리된 독자 세션

각 브라우저 인스턴스는 디렉토리 파티션이 완벽하게 독립되어 있습니다. 쿠키, 캐시, 세션 스토리지 및 로컬 데이터가 절대로 섞이지 않습니다.

실시간 무지연 동기화

내장 SSE(Server-Sent Events) 프로토콜을 통하여 호스트 브라우저에서의 스크롤, 클릭, 키다운 이벤트가 슬레이브 브라우저로 지연 없이 동기화됩니다.

지능형 봇 탐지 우회 (Human Jitter)

마우스 물리적 좌표가 똑같이 동기화될 경우 매크로 봇으로 감지됩니다. AMEVA는 무작위 물리 경로 지터링 및 베지에 곡선 스무딩을 적용하여 탐지를 완벽히 속입니다.

멀티 프록시 바인딩

각 세션 프로필 카드에 프록시 서버 주소(Host:Port:User:Pass)를 손쉽게 적용하십시오. 각 창이 전 세계의 개별 고유 IP로 패킷을 전송합니다.

정밀한 바탕화면 그리드 레이아웃

Electron의 윈도우 좌표 API를 이용해, 생성된 외부 브라우저 창들을 바탕화면에 1x2, 2x2, 3x2 혹은 임의의 행렬 모양으로 픽셀 정밀도로 정렬시킵니다.

Aero Glass & 스텔스 모드

작업 화면을 가리고 백그라운드에서 실행해야 할 때는 스텔스(은폐) 모드를 활성화하십시오. 시각 리소스를 차단하여 초경량 상태로 런타임을 유지합니다.

Architecture

시스템 아키텍처 및 내부 구조

Electron 기반의 메인 런처와 다중 격리 프로세스 간의 통신 시스템

AMEVA Launcher UI (Master)

Electron Chromium 기반 메인 윈도우. 글로벌 세팅, 그리드 관리 및 HTTP/SSE 마스터 서버 작동.

SSE Event Broadcast (Port 8080)

Host 브라우저의 마우스/키보드 이벤트 캡처 데이터 수신 후 각 Slave 브라우저로 Real-time SSE push.

Isolated Browser Instances (Slaves)

독립된 Chrome/Edge 세션. 핑거프린트 우회 및 프록시 파티션이 개별 바인딩되어 독립 실행.

비즈니스 작업 자동화의 패러다임을 바꾸십시오.

AMEVA Multi-Session Browser Launcher는 마케팅 대행사, 다중 트래픽 검증 연구소, 애널리틱스 분석가 및 QA 테스트 업계를 위한 강력한 무기입니다.
